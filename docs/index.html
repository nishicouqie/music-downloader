三步用起来

  1. 1

    下载并解压

    到 Releases 下载压缩包，解压到任意普通目录，比如 D:\音乐下载器\。

  2. 2

    双击运行

    运行 音乐下载器.exe。第一次 Windows 会拦一下，点「更多信息 → 仍要运行」。

  3. 3

    搜歌、点下载

    歌名、歌手、网易云链接、歌曲 ID 都能直接粘。文件默认存到 D:\音乐下载\。

💡 想要官方无损通道，就配一个自己的 VIP 账号

不配也能用，程序会自动走第三方接口。但配上你自己已经付费购买的网易云黑胶 Cookie，就能走官方通道 —— 更稳定、更合规，也是你的正当权益。

拿 Cookie：登录 music.163.com → F12 → Application → Cookies → 复制 MUSIC_U 的值 → 程序里「设置 → 添加账号」。可以存多组。

常见问题

双击 exe 一闪而过，没有窗口？

程序所在的目录路径有问题。已知 D:\我的\程序\deepseek harness work\ 及其子目录下会出现这种情况（实测 100% 复现），原因是该环境下 pythonnet 加载 Python.Runtime.dll 失败。把整个文件夹剪切到别处即可。

除此之外，纯 ASCII、中文、带空格、长短路径都测试过，全部正常。

提示「所有音源通道都没能取到直链」？

三级通道全挂了。常见原因是第三方聚合接口临时限流或停止服务，或者这首歌在各个 平台都需要付费购买。处理办法：点「重试」；到设置里点「测试」检查 Cookie 是否 还有效；如果聚合接口长期不可用，就配一个自己的 VIP 账号走官方通道。

只有 128K，拿不到无损？

界面上会显示实际拿到的音质。如果显示「酷我 128K」，说明前两级通道都没成功， 降级到了兜底源。配一个网易云黑胶 VIP 账号走官方通道即可拿到无损。

为什么不用 Mp3tag 写标签？

Mp3tag 官方文档写得很明确："Mp3tag is built as an interactive program, further commands are currently not planned." 它只有 /fp 和 /fn 两个命令行参数，没有任何打标签的命令行接口，无法批处理。

所以本程序用 mutagen 直接读写标签 —— 做的事和 Mp3tag 内部完全一样， 生成的都是标准格式，随时可以丢进 Mp3tag 复核或再编辑。

会封号吗？

正常使用频率下没有发现问题。但请不要用它高频批量抓取 —— 那既可能触发风控， 也会给第三方服务造成负担。

能放到手机里听吗？

可以。下载完把 D:\音乐下载\ 里的文件拷到手机即可。长期听建议选 「MP3 320K」（体积小、兼容性好）；归档收藏选「FLAC 无损」。
